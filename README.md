# PDF Parser для оценок/неравенств
Скрипт для извлечения метаданных из научных статей в формате PDF, а также сбор данных по контексту оценок и неравенств

## Принцип работы

- Извлекает текст из PDF
- Разбивает слова
- Ищет предложения по ключевым словам
- Автоматически определяет метаданные статьи через Qwen 7b
- Сохраняет результат в .json и .txt

## Установка

### 1. Установка Python библиотек

```bash
pip install PyMuPDF
```

### 2. Установка Qwen 7b

- Требуется установить Ollama с официального сайта: https://ollama.com/
- Запускаем Ollama
- Затем надо сделать pull образа:

```bash
ollama pull qwen2.5:7b
```

### 3. Запуск

Можно запускать через любой IDE поддерживающий Python >= 3.8. Работа была выполнена используя VS Code 2022
